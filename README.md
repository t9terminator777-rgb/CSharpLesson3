# Практические задачи по C# — урок 3

Отдельный консольный проект с решениями задач из PDF. Предыдущие проекты не изменены.

## Запуск в VS Code

1. Открой в VS Code папку CSharpLesson3.
2. Открой терминал через меню Terminal → New Terminal.
3. Выполни команду:

    dotnet run

В меню выбери номер задания. Для выхода введи 0.

## Что сделано

1. **Банковский счёт** — абстрактный класс BankAccount, метод пополнения Deposit() и абстрактный метод снятия Withdraw(). В SavingsAccount проверяется минимальный остаток 1000, а в CheckingAccount при снятии добавляется комиссия 50.
2. **Оплата** — интерфейс IPaymentMethod и реализации CreditCard, PayPal, BankTransfer.
3. **Заказ товара** — ввод количества и цены, обработка неверного формата и отрицательных значений через try/catch, расчёт итоговой суммы.
4. **Журнал событий** — при каждом запуске в log.txt добавляется время входа, затем журнал выводится на экран. Пункт меню позволяет посмотреть его ещё раз.
5. **Загрузка отчёта** — async, await и Task.Delay() имитируют получение отчёта; результат сохраняется в report.txt.
6. **Обновление данных** — курсы валют, новости и погода загружаются параллельно с помощью Task.WhenAll(). Значения демонстрационные, интернет-запросы не выполняются.

В исходном PDF после задачи 5 сразу указана задача 7; задачи 6 в документе нет. В меню все шесть найденных задач пронумерованы подряд.

Файлы log.txt и report.txt создаются во время работы и не добавляются в GitHub. Папки bin и obj тоже исключены из Git.
